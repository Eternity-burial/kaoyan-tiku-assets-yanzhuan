## 三、 使用场景与调用建议

1. **本地沉浸式阅读与刷题**：
   - 政治真题：直接阅读 [`政治/历年真题/2026年考研政治真题.md`](./政治/历年真题/2026年考研政治真题.md)，各题干后附带标注与详细考点定位；
   - 英语精读：直接阅读 [`英语/英语一/真题精读与长难句/[2025-Text1] 2025年Text1精读与语法树.md`](./英语/英语一/真题精读与长难句/[2025-Text1]%202025年Text1精读与语法树.md)，阅读试题陷阱剖析与逐句语法树一目了然；
   - 数学破题：直接查阅 [`数学/破题诀讲义/`](./数学/破题诀讲义/)，每篇包含题眼判定、标准步法与真题样板。

2. **程序化检索与题库开发**：
   - 数学真题与解析：通过题目 `id` 从 [`数学/多维题解/solutions_8000.json`](./数学/多维题解/solutions_8000.json) 直接查表；
   - 政治题目：通过 [`政治/历年真题/politics_real_all.json`](./政治/历年真题/politics_real_all.json) 进行考点分类检索；
   - 英语长难句：通过 `sid`（如 `en1-2025-text1-s1`）从 [`英语/英语一/reading_passages_all.json`](./英语/英语一/reading_passages_all.json) 直接获取主干 `trunk` 与成分 `components`。
