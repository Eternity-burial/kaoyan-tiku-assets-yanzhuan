# [GS03-M05] 拐点的求法

> **所属板块**：GS03 一元微分·应用  
> **核心口诀**：解出 f''=0 只是候选，不变号就不算；还有 f'' 不存在的点别漏  
> **核心考点**：拐点、凹凸区间、二阶导变号、拐点坐标、凹凸性  

---

## 什么时候用

题目要「求拐点 / 拐点坐标 / 拐点个数 / 凹凸区间」，
或者把拐点当**中间步骤**——先求拐点，再在拐点处作切线、算面积、转旋转体。

它和 GS03-M01 是同一套逻辑差一阶：那边看 $f'$ 变号定极值，这边看 $f''$ 变号定拐点。
所以真题里两者经常同题出现（2023 年数二那道「无极值点但有拐点求参数」就是把两条判据一起考）。

近十年出现过的外壳：裸函数（2019 年数二、数三各一道，同一条曲线）、
**含绝对值的分段函数**（2021 年数二）、**先解微分方程再求拐点**（2019 年数一）、
**变限积分**（2025 年三卷同题）、**先求拐点再算旋转体体积**（2026 年数二）。


## 怎么做

**先把定义摆正：拐点是曲线上凹凸性改变的那个点。**
所以它是**曲线上的点**，有横坐标也有纵坐标。

**第一步：列候选点，两类。**

$$\text{候选点}=\{\,f''(x)=0\,\}\ \cup\ \{\,f''(x)\ \text{不存在}\,\}$$

⚠️ 第二类最常被漏，**含绝对值或分段时必然存在**。

**第二步：逐个验 $f''$ 在两侧是否变号。** 变号才是拐点，不变号就不是。
这一步就是本条的全部技术含量，而且**每年都有人在这里丢分**。

2019 年数二选择：曲线 $y=x\sin x+2\cos x$（$-\frac\pi2<x<2\pi$）的拐点是什么。
$$y'=\sin x+x\cos x-2\sin x=x\cos x-\sin x,$$
$$y''=\cos x-x\sin x-\cos x=-x\sin x .$$
$y''=0\Rightarrow x=0$ 或 $\sin x=0$，在区间内给出 $x=0$ 与 $x=\pi$ **两个候选**。
- $x=0$：两侧 $-x\sin x\approx-x^2<0$，**符号不变**——**不是拐点**；
- $x=\pi$：左边 $\sin x>0$ 故 $y''<0$，右边 $\sin x<0$ 故 $y''>0$，**变号**——是拐点。

$y(\pi)=\pi\cdot0+2(-1)=-2$，答案 $(\pi,-2)$。
**同一条曲线在同一年的数三卷上又考了一次**（区间改成 $-\frac\pi2<x<\frac{3\pi}2$），
答案一样。**$x=0$ 这个"解出来了但不变号"的候选点，就是这道题的全部设计。**

**第三步：看题目要「拐点」还是「横坐标」。**
要拐点就得**回代求 $y$**，写成坐标对；只问横坐标才单写 $x$。

**外壳一：分段/含绝对值，分段求 $f''$ 再逐段定号。**
2021 年数二解答：$f(x)=\dfrac{x|x|}{1+x}$，求凹凸区间及渐近线。
拆开：$x\ge0$ 时 $f=\dfrac{x^2}{1+x}=x-1+\dfrac1{1+x}$，$f''=\dfrac{2}{(1+x)^3}$；
$x<0$ 时 $f=-\dfrac{x^2}{1+x}$，$f''=-\dfrac{2}{(1+x)^3}$。
- $x<-1$：$(1+x)^3<0$，$f''>0$，**凹**；
- $-1<x<0$：$f''<0$，**凸**；
- $x>0$：$f''>0$，**凹**。

$x=-1$ 不在定义域内（那里是铅直渐近线），
而 $x=0$ 处 $f''$ 左右异号且 $f(0)=0$，故 $(0,0)$ **是拐点**。

**外壳二：曲线要先解出来。**
2019 年数一解答：$y'+xy=\mathrm{e}^{-x^2/2}$，$y(0)=0$，求凹凸区间与拐点。
先解一阶线性方程（GS07）：积分因子 $\mathrm{e}^{x^2/2}$，
$\bigl(y\mathrm{e}^{x^2/2}\bigr)'=1$，故 $y=x\mathrm{e}^{-x^2/2}$。
$$y'=(1-x^2)\mathrm{e}^{-x^2/2},\qquad y''=x(x^2-3)\mathrm{e}^{-x^2/2}.$$
$y''=0\Rightarrow x=0,\pm\sqrt3$，三个都变号，
故凹区间 $(-\sqrt3,0)$ 与 $(\sqrt3,+\infty)$、凸区间 $(-\infty,-\sqrt3)$ 与 $(0,\sqrt3)$，
拐点 $\bigl(-\sqrt3,-\sqrt3\mathrm{e}^{-3/2}\bigr)$、$(0,0)$、$\bigl(\sqrt3,\sqrt3\mathrm{e}^{-3/2}\bigr)$。

**外壳三：拐点只是第一小步。**
2026 年数二解答先要求出 $y=\dfrac1{1+x^2}$（$x\ge0$）的拐点 $M$，再拿它去围区域算旋转体体积。
$$y''=\frac{6x^2-2}{(1+x^2)^3}=0\ \Longrightarrow\ x_0=\frac{\sqrt3}{3},\qquad y_0=\frac34 .$$
2018 年数三/数二同题则是**先求拐点再在拐点处作切线**：
$y=x^2+2\ln x$，$y''=2-\dfrac2{x^2}=0\Rightarrow x=1$（$x>0$），拐点 $(1,1)$，
斜率 $y'(1)=2+2=4$，切线 $y=4x-3$。

## 边界与易错

**1. 只解 $f''=0$，不验变号。** 本条第一高发错误，上面 2019 那道整题就考它。
**写完候选点，逐个画符号线。**

**2. 漏掉 $f''$ 不存在的点。**
含 $|x|$、$\sqrt[3]{x}$、分段时必查。判据和极值那边一样：
**候选点永远是「导数为零」∪「导数不存在」两类。**

**3. 拐点写成一个数。**
问「拐点」答坐标、问「横坐标」答一个数。2019 年数二问的是「拐点是」，
答案必须是 $(\pi,-2)$；写 $\pi$ 就丢分。

**4. 拐点处不一定不可导，也不要求 $f''$ 存在。**
$y=\sqrt[3]{x}$ 在 $0$ 处 $f''$ 不存在，但 $(0,0)$ 是拐点。
**「拐点」是关于凹凸性的，不是关于可导性的。**

**5. 别把「$f''(x_0)=0$」当成拐点的充分条件，也别当成必要条件用错方向。**
- $f''(x_0)=0$ **推不出**拐点（$y=x^4$ 在 $0$ 处）；
- 拐点处**若 $f''$ 存在**则必为 $0$；但 $f''$ 可以不存在（见上条）。

**6. 「无极值但有拐点」这类反求题，两个不等号一个带等号一个不带。**
2023 年数二选择：$f=(x^2+a)\mathrm{e}^x$。
$f'=\mathrm{e}^x(x^2+2x+a)$，**无极值**要求它不变号，即 $\Delta\le0$（重根不变号，等号可取），得 $a\ge1$；
$f''=\mathrm{e}^x(x^2+4x+a+2)$，**有拐点**要求它变号，即 $\Delta>0$（必须两个不同实根），得 $a<2$。
答案 $[1,2)$。**四个选项差的就是这两个等号。**

**7. 变限积分载体：先求两次导，别看外形。**
2025 年三卷同题里 $g(x)=\displaystyle\int_0^x\mathrm{e}^{t^2}\mathrm dt\cdot\sin^2x$，
在 $0$ 附近 $\approx x\cdot x^2=x^3$，$g''\approx6x$ 变号，故 $(0,0)$ 是 $g$ 的拐点；
而同题的 $f(x)=\displaystyle\int_0^x\mathrm{e}^{t^2}\sin t\,\mathrm dt$ 的 $f''(0)=1\ne0$，
$(0,0)$ **不是** $f$ 的拐点，$x=0$ 是它的极值点。
**一道题两个函数，一个考拐点一个考极值，交叉着问。**

**相邻的招**：同一套变号逻辑用在一阶导上 → 求单调区间与极值（GS03-M01）；
要证明凹凸性的等价刻画（充要条件双向证）→ 凹凸性的等价刻画（GS03-M06）；
选项在「点处 $f''>0$」与「邻域内是凹的」之间绕 → 单调与凹凸的概念辨析（GS03-M03）；
求出拐点后要在该点作切线 → 切线与法线（GS03-M08）；
曲线要先解微分方程 → GS07。
