### 第 1 题 [单选题 · None]

爱迪生发明电灯之前做了两千多次试验。有个年轻记者曾经问他为什么遭遇这么多次失败。爱迪生回答：“我一次都没有失败，我发明了电灯。这只是一段经历了两千步的历程”。爱迪生之所以说“我一次都没有失败”是因为他把每一次实验都看作：

- **A**. 认识中所获得的相对真理
- **B**. 整个实践过程中的一部分 [★正确答案]
- **C**. 对事物规律的正确反映
- **D**. 实践中可以忽略不计的偶然挫折

- **【官方标准答案】**：`B`
- **【考点定位与精析】**：

```
[难度系数]0.726本题考查的考点是：实践活动的具体形式。题干中爱迪生发明电灯之前做的两千多次的实验都不是失败，而是不断向取得成功又近了一步，是整个发明实验活动的一个过程，一个部分，因此，正确选项是B。【干扰项辨识】选项A，正确反映事物规律的是真理，不是每一次实验。因此，排除。选项C，实践活动中的偶然性是不稳定的、暂时的、不确定的，偶然背后隐藏着必然，受必然的支配，所以不是忽略不计的，偶然挫折也不符合题目的科学实验活动，因此，排除。选项D，实验是客观的实践活动，不是真理。因此，排除。必背金句：实践的具体形式可分为三种基本类型，即物质生产实践、社会政治实践和科学文化实践。①物质生产实践是人类最基本的实践活动，决定着社会的基本性质和面貌。②社会政治实践是改造社会关系的实践活动，表现为人们之间的社会交往和政治活动。③科学文化实践是创造精神文化产品的实践活动。
```

### 第 2 题 [单选题 · None]

俄国早期马克思主义理论家普列汉诺夫说，绝不会有人去组织一个“月食党”以促进或阻止月食的到来，但要进行社会革命就必须组织革命党。这是因为社会规律与自然规律有所不同，它是：

- **A**. 不具有重复性的客观规律
- **B**. 由多数人的意志决定的
- **C**. 通过人的有意识的活动实现的 [★正确答案]
- **D**. 比自然规律更易于认识的规律

- **【官方标准答案】**：`C`
- **【考点定位与精析】**：

```
[难度系数]0.925本题考查的考点是：自然规律和社会规律。自然规律和社会规律都具有客观性，都不可以被改造或创造。但是两者的区别在于，自然规律是盲目无意识的力量在起作用，社会规律是通过有一定目的和意图的人的有意识的活动来实现的。因此，正确选项是C。【干扰项辨识】选项A，不管是自然规律还是社会规律都具有重复性。因此，排除。选项B，无论是物质世界的规律，还是人类社会历史的规律，都是不以个人意志为转移的客观规律。因此，排除。选项D，自然规律和社会规律并无哪个更容易认识的区分。因此，排除。必背金句：规律是事物联系和发展过程中所固有的本质的.必然的、稳定的联系。规律是客观的，客观性是规律的根本特性，它的存在不依赖于人的意识，但是，人的意识指导下的实践活动却是受规律的支配。规律的客观性表明，人们不能藐视规律，更不能创造和消灭规律，人们在实践中可以认识或发现规律，还可以通过改变规律发生作用的条件和形式，从而利用规律。
```

### 第 3 题 [单选题 · 马原]

社会生产是连续不断进行的，这种连续不断重复的生产就是再生产。每次经济危机发生期间，总有许多企业或因产品积压，或因订单缺乏等致使其无法继续进行再生产而被迫倒闭。那些因产品积压而倒闭的企业主要是由于无法实现其生产过程中的

- **A**. 劳动补偿
- **B**. 价值补偿 [★正确答案]
- **C**. 实物补偿
- **D**. 增殖补偿

- **【官方标准答案】**：`B`
- **【考点定位与精析】**：

```
【解析】社会再生产要连续进行，关键在于社会总产品必须得到“补偿”，包括价值补偿和实物补偿。
①价值补偿：生产中所耗费的资本得到价值补偿（商品→能卖出去→实现价值）
②实物补偿：生产过程中所耗费的生产资料和消费资料得到实物的替换（能买到生产的原材料）
题目中“因产品积压而倒闭的企业”这意味着：生产过程中耗费的资本价值（成本）无法收回，即价值补偿中断。由于没钱，自然也无法购买新的生产资料进行下一次生产（实物补偿也中断）。因此，企业倒闭的直接和最主要的原因是无法实现价值补偿。
【干扰选项】
AD选项：“劳动补偿、增殖补偿”不是一个标准的经济学术语。不用辨析。C选项：题干中，企业是因产品积压（无法实现价值补偿）而倒闭，而不是因为市场上买不到所需的生产资料。
```

### 第 4 题 [单选题 · 马原]

与第二次世界大战前的资本主义相比，当代资本主义在许多方面已经并正在发生着深刻的变化。正确分析这些新变化发生的原因，有利于我们科学而全面地认识当代资本主义社会。导致当代资本主义新变化发生的根本推动力量是

- **A**. 改良主义政党对资本主义制度的改革
- **B**. 工人阶级争取自身权利的斗争
- **C**. 科学技术革命和生产力的发展 [★正确答案]
- **D**. 社会主义制度的优越性对资本主义的影响

- **【官方标准答案】**：`C`
- **【考点定位与精析】**：

```
本题考查第二次世界大战后资本主义变化的主要表现、原因和实质
当代资本主义新变化的原因有很多。科学技术革命和生产力的发展，是资本主义变化的根本推动力量。应选C项。
工人阶级争取自身权利和利益的斗争，是推动资本主义变化的力量；社会主义制度初步显示的优越性对资本主义产生了一定影响；主张改良主义的政党对资本主义制度的改革，也对资本主义的变化发挥了重要作用。A、B、D三项都是导致当代资本主义新变化的原因，但最根本的原因是C项。
【刷题笔记】
①第二次世界大战后资本主义变化的原因和实质：首先，科学技术革命和生产力的发展，是资本主义发生变化的根本推动力量；其次，工人阶级争取自身权利和利益的斗争，是推动资本主义发生变化的重要力量；再次，社会主义制度初步显示的优越性对资本主义产生了重要影响；最后，主张改良主义的政党对资本主义制度的改革，也对资本主义发生变化起到了重要作用。
②虽然第二次世界大战后资本主义发生了一些变化，但是并没有改变资本主义制度的本质，并没有克服资本主义的基本矛盾，也没有改变马克思关于资本主义的基本论断的科学性。
③当代资本主义主要是指自第二次世界大战结束以来西方发达国家的国家垄断资本主义。
【真题思维点拨】
常规知识点理解记忆，请多看总结的刷题笔记并分析知识点。
```

- **A**. 我国社会存在着生产要素的多种所有制 [★正确答案]

### 第 11 题 [单选题 · None]

1930年11月毛泽东在《星星之火可以燎原》一文中写道：“我所说的中国革命高潮快要到来，绝不是如有些人所谓‘有到来之可能’那样完全没有行动意义的、可望而不可即的一种空的东西。它是站在海洋中，已经看得见桅杆尖头了的一只航船。它是立于高山之巅远看东方已见光芒四射喷薄欲出的一轮朝日。它是躁动于母腹中的快要成熟了的一个婴儿”这段话是针对当时党内和红军中存在的：

- **B**. “红旗到底打得多久”的疑问 [★正确答案]
