### 第 1 题 [单选题 · None]

某地区进入供暖季后常出现雾霾，而一旦出现大风天气或等到春暖花开后雾霾就会散去减少，从该地区较长时间的数据变化看，经过人们努力治霾，污染物排放总量在持续走低，但在某些时段，环境空气质量污染指数会迅速攀升，甚至“爆表”，这种看似“矛盾”的现象凸显了大气污染防治的一个特点：天帮忙很重要，但人努力才是根本。“人努力”与“天帮忙”之间的关系对我们处理主观能动性和客观规律之间辩证关系的启示是：

- **A**. 尊重事物的客观规律是正确发挥主观能动性的前提 [★正确答案]
- **B**. 人类有意识的思想活动是掌握客观规律的根本前提
- **C**. 认识活动是客观规律性与主观能动性相统一的基础
- **D**. 尚未认识的外在自然规律对人的实践活动起着至关重要的作用

- **【官方标准答案】**：`A`
- **【考点定位与精析】**：

```
[难度系数]0.595本题考查的考点是：主观能动性和客观规律性的辩证统一。题干中的“人努力”就是要发挥人的主观能动性，而“天帮忙”就是要遵循客观自然规律。两者之间就是主观能动性和客观规律性的辩证统一。因此，正确选项是A。【干扰项辨识】选项B，尊重客观规律是正确发挥主观能动性的前提。排除。选项C，实践是客观规律性与主观能动性统一的基础。排除。选项D，因为一些自然现象确实还没有被完全认识，也存在一些没有被发现的规律，所以“尚未认识的外在自然规律对人的实践活动起着至关重要的作用”，但这里只强调了客观规律，忽略了主观能动性的作用，因而并不体现题目要求的“辩证关系”。排除。必背金句：首先，尊重客观规律是正确发挥主观能动性的前提。其次，只有充分发挥主观能动性，才能正确认识和利用客观规律。承认规律的客观性，并不是说人在规律面前是无能为力的。实践是客观规律性与主观能动性统一的基础。
```

### 第 2 题 [单选题 · None]

有人认为，既然人的意识是对客观外部世界的反映，那么人脑里的“鬼”、“神”意识就是对外在世界鬼、神真实存在的反映。这种观念错误在于

- **A**. 夸大了意识的能动作用
- **B**. 把意识看成是物质的产物
- **C**. 认为意识是对存在的直接反映 [★正确答案]
- **D**. 混淆了人类意识自然演化的阶段

- **【官方标准答案】**：`C`
- **【考点定位与精析】**：

```
[难度系数]0.697本题考查的考点是：意识的本质。题干中人脑中“鬼”“神”的观念是对外在世界“鬼”“神”真实存在的反映。但外在世界并没有“鬼”“神”的真实存在，所以，错误在于意识是对外在世界的直观反映。直观反映就是脱离了实践、脱离了辩证法的一种错误认识。因此，正确选项是C。【干扰项辨识】选项A，意识具有能动作用，但夸大意识能动作用是一种错误，题干中的内容不是由夸大意识能动作用引起的。因此，排除。选项B，题干考查的是错误的原因，而“意识是物质的产物”这本身是正确的。因此，排除。选项D，意识的形成经历了三个阶段，但题干考查错误的原因，与意识的自然演化阶段无关。因此，排除。必背金句：从意识本质来看，意识是特殊的物质人脑的机能和属性，是客观世界的主观映象，意识在内容上是客观的，在形式上是主观的，是客观内容和主观形式的统一。意识是物质的产物，但又不是物质本身。
```

### 第 3 题 [单选题 · 马原]

某企业投资汽车生产，生产一辆汽车所耗费的生产资料价值为15万元，支付给工人的工资为5万元，假定市场的平均利润率为10%，那么，在自由竞争条件下，该汽车的生产价格是

- **A**. 20万元
- **B**. 20.5万元
- **C**. 21.5万元
- **D**. 22万元 [★正确答案]

- **【官方标准答案】**：`D`
- **【考点定位与精析】**：

```
本题考查生产价格的计算。根据马克思主义政治经济学的基本知识可知，生产价格=成本价格(预付资本)+平均利润。由题干可知，不变资本c为15万元，可变资本v为5万元，可以得出成本价格(预付资本)为20万元。由于平均利润率是10%，因此，投入20万元获得的平均利润就是2万元，成本价格(预付资本)与平均利润相加，可计算出生产价格为22万元。因此，选项D正确。选项A、B、C，均计算错误。
```

### 第 4 题 [单选题 · 马原]

从历史发展的角度看，资本主义生产资料所有制是不断演进和变化的。当今资本主义社会居主导地位的资本所有制形式是

- **A**. 私人资本所有制
- **B**. 法人资本所有制 [★正确答案]
- **C**. 私人股份资本所有制
- **D**. 垄断资本私人所有制

- **【官方标准答案】**：`B`
- **【考点定位与精析】**：

```
本题考查资本主义所有制形式的变化。资本主义所有制形式先后经历了私人资本所有制、私人股份资本所有制、国家资本所有制和法人资本所有制。而当今居于主导地位的是法人资本所有制，所谓的“法人”，指的是企业或者其他社会组织在法律上取得的人格，如果企业作为一个独立的“法人”去持有另外一家企业的股份，这就是法人资本所有制。例如，阿里巴巴公司作为一个法人，可以成为新浪公司的股东。因此，选项B正确。选项A、C、D，三个选项中的所有制形式都是资本主义社会曾经有过，或者现在仍然存在的所有制形式，但并非当今最主要的形式，故排除。
```

### 第 5 题 [单选题 · None]

从中华人民共和国成立到社会主义改造完成，是我国从新民主主义到社会主义的过渡时期。这一时期，个体经济向社会主义集体经济过渡形式是

- **A**. 国营经济
- **B**. 私人资本主义经济
- **C**. 合作社经济 [★正确答案]

```

```

### 第 9 题 [单选题 · 史纲]

帝国主义侵略中国的最终目的，是要瓜分中国、灭亡中国。1895年中国在甲午战争中战败后，列强掀起了瓜分中国的狂潮，这集中表现在

- **A**. 竞相租借港湾和划分势力范围 [★正确答案]
- **B**. 外国资本在中国近代工业中争夺垄断地位
- **C**. 设立完全由外国人直接控制和统治的租界
- **D**. 从侵占中国周边邻国发展到蚕食中国边疆地区

- **【官方标准答案】**：`A`
- **【考点定位与精析】**：

```
本题考查帝国主义瓜分中国的图谋。中日《马关条约》规定把台湾及其附属岛屿、澎湖列岛和辽东半岛割让给日本，大大刺激了帝国主义列强瓜分中国领土的野心，并激化了列强争夺中国的矛盾。俄、德、法三国以干涉还辽“有功”为由，要求租借中国港湾作为报酬。由此，德、俄、英、法、日等国于1898年至1899年竞相租借港湾和划分势力范围，掀起了瓜分中国的狂潮。因此，选项A正确。选项B，“外国资本在中国近代工业中争夺垄断地位”是外国资本进入中国后始终都在进行的阴谋，并非中日甲午战争之后才有的。选项C，“设立完全由外国人直接控制和统治的租界”最早可以追溯到1845年11月15日，英国在中国上海设立了近代史上的第一块租界，这是完全由外国人直接控制中国租界的开端。选项D，“从侵占中国周边邻国发展到蚕食中国边疆地区”可以追溯到19世纪70至80年代，使中国陷入“边疆危机”。
```

### 第 10 题 [单选题 · None]

第一次世界大战，德国战败。1918年12月，陈独秀在《每周评论》里的发刊词中说大战结果是“公理战胜强权”，并把美国总统威尔逊称作“现在世界第一好人”，然而陈独秀在1919年5月4日出版的《每周评论》上的一片文章中又写到“什么公理，什么永久和平，什么威尔逊总统十四条宣言，都成了一文不值的空话。”导致陈独秀认识发生变化的直接原因是

- **A**. 中国巴黎和会外交失败 [★正确答案]
- **B**. 日本对德国宣战，出兵山东
- **C**. 苏俄宣布废除以前同中国签订的一切不平等条约
- **D**. 美国不愿放弃在华种种特权

- **【官方标准答案】**：`A`
- **【考点定位与精析】**：

```
【难度系数】0.814本题考查的考点是：五四运动的发生和发展。五四运动的直接导火线，是巴黎和会上中国外交的失败。在1919年上半年召开的巴黎“和平会议”上，中国政府代表提出废除外国在中国的势力范围、撤退外国在中国的军队和巡警、撤销领事裁判权、归还租界、取消中日“二十一条”及换文等正义要求，遭到拒绝。同时，会议不顾中国代表的抗议，规定德国应将在中国山东获得的一切特权转交给日本，而北洋政府竞准备在这个丧权辱国的和约上签字。消息传到国内，激起了各阶层人民的强烈愤怒。五四运动由此爆发。题干中，陈独秀在《每周评论》中，对美国总统威尔逊的话语，揭示了威尔逊的实质，就是强权主义。因此，正确选项是A。【干扰项辨识】选项B，日本对德国宣战，出兵山东，这是一战时的，不符合题意。因此，排除。选项C，苏俄宣布废除以前同中国签订的一切不平等条约，发生在1919年7月25日，在巴黎和会之后。因此，排除。选项D，鸦片战争之后，美国已经攫取了很多特权，也一直没有放弃。这不是陈独秀认识发生变化的直接原因。因此，排除。
```

### 第 11 题 [单选题 · None]

毛泽东思想是马克思主义中国化的第一大理论成果，是在中国革命和建设的实践中逐步形成和发展起来的，在土地革命战争后期和抗日战争时期，毛泽东思想得到多方面展开而达到成熟，其标志是

- **B**. 新民主主义理论的系统阐释 [★正确答案]

- **D**. 思想政治工作和文化工作理论的系统提出
