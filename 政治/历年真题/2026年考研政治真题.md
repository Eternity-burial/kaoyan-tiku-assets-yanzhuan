### 第 1 题 [单选题 · 马原]

“十五五”时期在基本实现社会主义现代化进程中具有承前启后的重要地位。习近平总书记在《关于<中共中央关于制定国民经济和社会发展第十五个五年规划的建议>的说明》中指出：“实现社会主义现代化是一个阶梯式递进、不断发展进步的历史过程，需要不懈努力、持续奋斗。”“阶梯式递进、不断发展进步”的过程是一个
①前进性与曲折性相统一的过程
②规律性与能动性相统一的过程
③连续性与非连续性相统一的过程
④直线性与循环性相统一的过程

- **A**. ①②③ [★正确答案]
- **B**. ①②④
- **C**. ①③④
- **D**. ②③④

- **【官方标准答案】**：`A`
- **【考点定位与精析】**：

```
【考点定位】考点48 社会进步与社会形态

【简析】人类通过实践活动在不断改造世界过程中推动社会发展和进步。社会进步作为对社会前进发展的总概括，主要表现在两个方面：一是社会形态从低级到高级的发展。二是同一社会形态内部的发展。特定社会形态都有其相对稳定性，也都有其自身发展的过程，并可以通过内部改革促进自身的发展。当然，社会进步不是直线上升的，而是曲折发展的，有时甚至包含着某些停滞和倒退，但终究改变不了社会进步的总趋势，阻挡不住社会发展的历史进程。①正确。人类社会的发展是客观必然性和历史选择性的统一，即规律性与能动性相统一。②正确。实现社会主义现代化是一个阶梯式递进、不断发展进步的历史过程。“阶梯式递进、不断发展进步”的过程，体现了量变质变规律。量变是事物发展渐进过程的连续性，质变是事物发展渐进过程和连续性的中断。量变质变规律体现了事物发展的渐进性和飞跃性的统一。③正确。发展是事物变化中前进的、上升的运动。但是，事物的发展并非直线性上升，也不是封闭式的循环，而是表现为波浪式前进和螺旋式上升。④错误。因此，本题选A。
```

### 第 2 题 [单选题 · None]

一般认为，在重力的作用下，当树叶飘离枝头坠落地面时，密度大的叶片正面更容易朝下着地。科学研究表明，叶片的下落过程并非简单的直线下落，因为叶片形状并非完全对称，加之空气阻力、涡流和风等因素影响，叶片以翻滚和旋转的复杂运动形态下落。内部结构差异与外在形态变化在一定程度上影响着叶片的飘落状点，旋转功能和空气阻力也是影响叶片在下降过程中朝向的因素。叶片下落的过程表明，事物运动的规律

- **A**. 取决于外在因素作用的大小
- **B**. 是纯粹偶然因素作用的结果
- **C**. 取决于物质形态变化的规律
- **D**. 是各种因素相互作用的结果 [★正确答案]

- **【官方标准答案】**：`D`
- **【考点定位与精析】**：

```
本题考查的知识点:规律的客观性
外在因素对事物发展有推动或阻碍作用，不能起决定作用，A错。规律是一种必然性，不是纯粹偶然因素作用的结果，B错。物质是第一性的，只能决定其他，不能是取决于物质，C错。所以，本题正确答案为D。
```

### 第 3 题 [单选题 · None]

《孙子兵法》将变化视作军事运行的常态认为“兵无常势，水无常形”要使战争主动权始终掌握在自己手中，就要根据不同的情况灵活的应对。由此可知，“兵无常势，水无常形”契合了

- **A**. “原则是研究的出发点”的观点
- **B**. “理性是衡量一切的唯一尺度”的观点
- **C**. “意志自由只是借助于对事物的认识来作出决定”的观点 [★正确答案]
- **D**. “思维的本质在于把意识的因素联系合为一个统一体”的观点

- **【官方标准答案】**：`C`
- **【考点定位与精析】**：

```
本题考查的知识点:一切从实际出发、尊重客观规律
A 选项是典型的教条主义观点，认为主观原则是行动的出发点，和 “根据实际变化调整” 的思想完全相反，不符合题意。
B 选项是启蒙运动时期的理性主义观点，强调理性的绝对权威，忽视了具体情况的变化，和题干中 “灵活应变” 的思想不契合。
C 选项对，选项的核心是：人的自由选择（意志自由）不是随心所欲的，而是必须建立在对客观事物的正确认识之上，根据实际情况来决定行动。这和 “兵无常势，水无常形” 中 “依据敌情变化而取胜” 的思想高度契合。
D 选项是黑格尔唯心主义的观点，认为思维的本质是意识自身的综合，和题干中 “尊重客观变化、从实际出发” 的唯物主义思想无关。
```

### 第 31 题 [多选题 · None]

马克思指出“没有无义务的权利，也没有无权利的义务。”正确理解法律权利与法律义务的关系，是培养法治思维的前提条件。法律权利与法律义务的关系是

- **A**. 法律义务离开法律权利仍有履行的价值
- **B**. 所有法律权利和法律义务都具有复合性关系
- **C**. 法律权利的实现必须以相应法律义务的履行为条件 [★正确答案]
- **D**. 法律权利的存在和发展都必须以法律义务的存在和发展为条件 [★正确答案]

- **【官方标准答案】**：`CD`
- **【考点定位与精析】**：

```
本题考查的知识点:法律权利和义务的关系
法律权利与法律义务就像一枚硬币的两面，不可分割，相互依存。在社会生活中，每个人既是享受法律权利的主体，又是承担法律义务的主体。在法治国家，不存在只享受权利的主体，也不存在只承担义务的主体。法律权利的实现必须以相应法律义务的履行为条件;法律义务的设定和履行也必须以法律权利的行使为根据。离开了法律权利，法律义务就失去了履行的价值和动力;离开了法律义务，法律权利也形同虚设。有些法律权利和法律义务具有复合性的关系，即一个行为可以同时是权利行为和义务行为，如劳动的权利和义务、接受义务教育的权利和义务等。所以AB说法错误，
本题正确答案为CD。
```
