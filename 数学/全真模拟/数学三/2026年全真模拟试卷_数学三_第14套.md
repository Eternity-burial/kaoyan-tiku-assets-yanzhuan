### 第 1 题 (选择题 · 5分)

下列结论正确的是 ( ).

- **(A)** 曲线 \( y = x \sin \frac{1}{x} \) 和 \( y = x \cos \frac{1}{x} \) 均有斜渐近线
- **(B)** 曲线 \( y = x \sin \frac{1}{x} \) 和 \( y = x \cos \frac{1}{x} \) 均没有斜渐近线
- **(C)** 曲线 \( y = x \sin \frac{1}{x} \) 有斜渐近线, \( y = x \cos \frac{1}{x} \) 没有斜渐近线
- **(D)** 曲线 \( y = x \sin \frac{1}{x} \) 没有斜渐近线, \( y = x \cos \frac{1}{x} \) 有斜渐近线

> **标准答案**：`D`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

由于 \(\lim_{x\to \infty}x\sin \frac{1}{x} = 1\) ，所以 \(y = x\sin \frac{1}{x}\) 有水平渐近线 \(y = 1\) ，没有斜渐近线.
对于曲线  \( y = x \cos \frac{1}{x} \) ,
\[
\lim _ {x \rightarrow \infty} \frac {y}{x} = \lim _ {x \rightarrow \infty} \cos \frac {1}{x} = 1, \lim _ {x \rightarrow \infty} (y - x) = \lim _ {x \rightarrow \infty} x \left(\cos \frac {1}{x} - 1\right) = - \lim _ {x \rightarrow \infty} x \cdot \frac {1}{2 x ^ {2}} = - \lim _ {x \rightarrow \infty} \frac {1}{2 x} = 0,
\]
所以曲线  \( y = x \cos \frac{1}{x} \)  有斜渐近线 y = x.

</details>

### 第 2 题 (选择题 · 5分)

设函数 \( f(x) \) 在点 \( x = 0 \) 的某个邻域内有连续的导数, \( f(0) = 0 \), 且 \( \lim_{x \to 0} \frac{f(x) - f'(x)}{\ln(1 + x)} = -1 \), 则 ( ).

- **(A)** \(f(0)\) 是 \(f(x)\) 的极小值
- **(B)** \(f(0)\) 是 \(f(x)\) 的极大值
- **(C)** \(f(0)\) 不是 \(f(x)\) 的极值
- **(D)** 不能判别 \(f(0)\) 是否为 \(f(x)\) 的极值

> **标准答案**：`A`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

由题设有 \(\lim_{x\to 0}[f(x) - f'(x)] = f(0) - f'(0) = 0,f'(0) = 0\) ，当 \(x\to 0\) 时， \(\ln (1+\) \(x)\sim x\) ，由此可得 \(\lim_{x\to 0}\frac{f(x) - f'(x)}{\ln(1 + x)} = \lim_{x\to 0}\left[\frac{f(x) - f(0)}{x} -\frac{f'(x) - f'(0)}{x}\right] = f'(0) -\) \(f''(0) = -1\Rightarrow f''(0) = 1\) ，因此 \(f(0)\) 是 \(f(x)\) 的极小值.所以答案为A.

### 第 3 题 (选择题 · 5分)

设有曲线 \( y = \ln x \) 与 \( y = kx^2 \)，当 \( k > \frac{1}{2\mathrm{e}} \) 时，两曲线（）.

- **(A)** 没有交点
- **(B)** 仅有一个交点
- **(C)** 有两个交点
- **(D)** 有三个交点

> **标准答案**：`A`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

解法一 设 \(f(x) = \frac{\ln x}{x^2}, f'(x) = \frac{1 - 2\ln x}{x^3}\), 令 \(f'(x) = 0\) 得 \(x = \sqrt{\mathrm{e}}\).
当 \(0 < x < \sqrt{\mathrm{e}}\) 时，\(f'(x) > 0, f(x)\) 单调递增，且 \(\lim_{x \to 0^{+}} f(x) = -\infty\)；
当 \(x > \sqrt{\mathrm{e}}\) 时，\(f'(x) < 0, f(x)\) 单调递减，且 \(\lim_{x \to +\infty} f(x) = 0\)，故 \(f(x)\) 在 \(x = \sqrt{\mathrm{e}}\) 处取到最大值 \(f(\sqrt{\mathrm{e}}) = \frac{1}{2\mathrm{e}}, k > \frac{1}{2\mathrm{e}}\) 时，两曲线无交点.
解法二 两曲线交点横坐标满足方程 \(kx^{2} - \ln x = 0\) ，令
\[
f (x) = k x ^ {2} - \ln x, f ^ {\prime} (x) = 2 k x - \frac {1}{x} = 0 \Rightarrow x = \frac {1}{\sqrt {2 k}}, f \left(\frac {1}{\sqrt {2 k}}\right) = \frac {1}{2} + \frac {1}{2} \ln (2 k),
\]
当 \(k > \frac{1}{2\mathrm{e}}\) 时有 \(f\left(\frac{1}{\sqrt{2k}}\right) > 0, \lim_{x\to +\infty}f(x) = +\infty, \lim_{x\to 0^{+}}f(x) = +\infty\)，函数 \(f(x)\) 在区间
\(\left(0, \frac{1}{\sqrt{2k}}\right)\) 上单调递减，在 \(\left(\frac{1}{\sqrt{2k}}, +\infty\right)\) 上单调递增，因此方程 \(kx^2 - \ln x = 0\) 无实根，即两个曲线没有交点.

</details>

### 第 4 题 (选择题 · 5分)

设区域 \(D_{1}\) 为 \(x^{2} + y^{2} \leqslant 1\) 在第一象限的部分, \(D_{2}\) 为 \(|x| + |y| \leqslant 1\) 在第一象限的部分,
\[
I _ {1} = \iint_ {D _ {1}} \cos (\pi x y) d \sigma , I _ {2} = \iint_ {D _ {2}} \cos (\pi x y) d \sigma , I _ {3} = \iint_ {D _ {2}} \sin (\pi x y) d \sigma ,
\]
则（ ）.

- **(A)** \(I_{1} <   I_{2} <   I_{3}\)
- **(B)** \(I_{3} <   I_{2} <   I_{1}\)
- **(C)** \(I_{3} <   I_{1} <   I_{2}\)
- **(D)** \(I_{2} <   I_{3} <   I_{1}\)

> **标准答案**：`B`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

当 \((x, y) \in D_1\) 时，\(0 \leqslant \pi xy \leqslant \frac{\pi (x^2 + y^2)}{2} \leqslant \frac{\pi}{2}\)，所以 \(\cos (\pi xy) \geqslant 0\)。又 \(D_2 \subset D_1\)，所以 \(0 < I_2 < I_1\)。
当 \((x, y) \in D_2\) 时，\(0 \leqslant \pi xy \leqslant \pi x (1 - x) \leqslant \frac{\pi}{4}, \cos (\pi xy) > \sin (\pi xy)\)，所以 \(I_3 < I_2\). 综上，\(0 < I_3 < I_2 < I_1\).

</details>

- **(A)** \(\alpha_{1},\alpha_{2},\alpha_{3}\)
- **(B)** \(\alpha_{1} + \alpha_{2},\alpha_{2} + \alpha_{3},\alpha_{3} + \alpha_{1}\)
- **(C)** \(\alpha_{2},\alpha_{3},\alpha_{4}\)
- **(D)** \(\alpha_{1} + \alpha_{2},\alpha_{2} + \alpha_{3},\alpha_{3} + \alpha_{4},\alpha_{4} + \alpha_{1}\)

> **标准答案**：`C`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

已知方程组 Ax=0 的通解为  \( k(1,0,-1,0)^{\mathrm{T}} \) ，故  \( r(A)=4-1=3, r(A^{*})=1 \) ，所以方程组  \( A^{*}x=0 \)  的基础解系含 3 个解向量.
又因为  \( A^{*}A=0 \) ，所以 A 的列向量组  \( \alpha_{1},\alpha_{2},\alpha_{3},\alpha_{4} \)  均为  \( A^{*}x=0 \)  的解向量。由于方程组 Ax=0 的解为  \( (1,0,-1,0)^{\mathrm{T}} \) ，故  \( \alpha_{1}=\alpha_{3} \) ，从而  \( \alpha_{1},\alpha_{2},\alpha_{3} \)  线性相关， \( \alpha_{1}+\alpha_{2},\alpha_{2}+\alpha_{3},\alpha_{3}+\alpha_{1} \)  线性相关，故 A,B 不正确。
因 \(r(\mathbf{A}) = 3\) ，故 \(\pmb{\alpha}_{1},\pmb{\alpha}_{2},\pmb{\alpha}_{3},\pmb{\alpha}_{4}\) 存在3个线性无关的向量，由 \(\pmb{\alpha}_{1} = \pmb{\alpha}_{3}\) ，知 \(\pmb{\alpha}_{1},\pmb{\alpha}_{2},\pmb{\alpha}_{3}\) 和 \(\pmb{\alpha}_{1}\) \(\pmb{\alpha}_{3},\pmb{\alpha}_{4}\) 均线性相关，余下的 \(\pmb{\alpha}_{2},\pmb{\alpha}_{3},\pmb{\alpha}_{4}\) 和 \(\pmb{\alpha}_{1},\pmb{\alpha}_{2},\pmb{\alpha}_{4}\) 是同一向量组，故 \(\pmb{\alpha}_{2},\pmb{\alpha}_{3},\pmb{\alpha}_{4}\) 必线性无关，C正确.
因为方程组  \( A^{*}x=0 \)  的基础解系含 3 个解向量, 所以 D 不正确.

### 第 7 题 (选择题 · 5分)

### 第 8 题 (选择题 · 5分)

- **(A)** \(3x^{2}\)
- **(B)** \(3(1 - x)^{2}\)
- **(C)** \(1 + 2x - 3x^{2}\)
- **(D)** \(4x - 3x^{2}\)

> **标准答案**：`D`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

由题设得当 \(0 \leqslant x \leqslant 1\) 时, \(X_{1}, X_{2}, X_{3}\) 的分布函数均为 \(F(x) = x\), 从而有 \(\min\{X_{1}, X_{2}\}\) 的分布函数为 \(1 - [1 - F(x)]^{2} = 1 - (1 - x)^{2}\), 所以 \(X = \max\{\min\{X_{1}, X_{2}\}, X_{3}\}\) 的分布函数为
\[
F (x) \{1 - [ 1 - F (x) ] ^ {2} \} = x [ 1 - (1 - x) ^ {2} ] = 2 x ^ {2} - x ^ {3},
\]
所以当 \(0 \leqslant x \leqslant 1\) 时，\(X\) 的概率密度 \(f_{X}(x) = (2x^{2} - x^{3})' = 4x - 3x^{2}\).

### 第 10 题 (选择题 · 5分)

设 \(X_{1}, X_{2}, X_{3}, X_{4}\) 为来自总体 \(X \sim N(0,1)\) 的一个简单随机样本, 以下四个命题:
① \(X_{1} + 2X_{2}\) 与 \(2X_{3} - X_{4}\) 同分布；
② \(X_{1}^{2}\) 与 \(\frac{(X_2 - X_3 + X_4)^2}{3}\) 同分布；
③ \(\frac{X_1 - X_2}{|X_3 + X_4|}\) 与 \(\frac{X_1 - X_2}{|X_1 + X_2|}\) 同分布；
④ \(\frac{X_1^2 + X_2^2}{X_3^2 + X_4^2}\) 与 \(\frac{(X_1 + X_2)^2}{X_3^2 + X_4^2}\) 同分布.

- **(B)** 2
- **(C)** 3
- **(D)** 4

> **标准答案**：`C`  

<details>
<summary><b>点击查看深度推导与解析</b></summary>

由于  \( X_{1}+2X_{2}\sim N(0,5) \) ， \( 2X_{3}-X_{4}\sim N(0,5) \) ，故①正确.

由于 \(\frac{X_1 - X_2}{\sqrt{2}}\sim N(0,1)\) ，因为 \(\frac{X_3 + X_4}{\sqrt{2}}\sim N(0,1)\) ，所以 \(\frac{(X_3 + X_4)^2}{2}\sim \chi^2 (1)\) ，又
\(\frac{X_1 - X_2}{\sqrt{2}}\) 与 \(\frac{(X_3 + X_4)^2}{2}\) 相互独立，故 \(\frac{\frac{X_1 - X_2}{\sqrt{2}}}{\sqrt{\frac{(X_3 + X_4)^2}{2}} / 1} = \frac{X_1 - X_2}{|X_3 + X_4|} \sim t(1)\).
由于 \(\frac{X_1 - X_2}{\sqrt{2}} \sim N(0,1)\), 因为 \(\frac{X_1 + X_2}{\sqrt{2}} \sim N(0,1)\), 所以 \(\frac{(X_1 + X_2)^2}{2} \sim \chi^2(1)\). 又由题意知 \((X_1 - X_2, X_1 + X_2)\) 服从二维正态分布, 且 \(\operatorname{Cov}(X_1 - X_2, X_1 + X_2) = DX_1 - DX_2 = 1 - 1 = 0\), 所以 \(X_1 - X_2\) 与 \(X_1 + X_2\) 不相关, 从而有 \(X_1 - X_2\) 与 \(X_1 + X_2\) 相互独立, 所
以 \(\frac{X_1 - X_2}{\sqrt{2}}\) 与 \(\frac{(X_1 + X_2)^2}{2}\) 相互独立，因此 \(\frac{\frac{X_1 - X_2}{\sqrt{2}}}{\sqrt{\frac{(X_1 + X_2)^2}{2} / 1}} = \frac{X_1 - X_2}{|X_1 + X_2|} \sim t(1)\). 故③
正确.

| \lambda \boldsymbol {E} - \boldsymbol {A} | = \left| \begin{array}{c c c} \lambda - 1 & 2 & - 2 \\ 2 & \lambda - 4 & 4 \\ - 2 & 4 & \lambda - 4 \end{array} \right| = \lambda^ {2} (\lambda - 9),
\]
可知 A 的特征值为  \( \lambda_{1} = \lambda_{2} = 0, \lambda_{3} = 9. \)
当 \(\lambda_{1} = \lambda_{2} = 0\) 时，解 \((0E - A)x = 0\) 得正交的基础解系为
\[
\boldsymbol {\xi} _ {1} = (2, 1, 0) ^ {\mathrm{T}}, \boldsymbol {\xi} _ {2} = (- 2, 4, 5) ^ {\mathrm{T}}.
\]
当 \(\lambda_{3} = 9\) 时，解 \((9E - A)x = 0\) 得基础解系 \(\pmb{\xi}_3 = (1, - 2,2)^{\mathrm{T}}\)
将 \(\pmb{\xi}_1, \pmb{\xi}_2, \pmb{\xi}_3\) 单位化，得 \(p_1 = \frac{1}{\sqrt{5}} (2, 1, 0)^{\mathrm{T}}, p_2 = \frac{1}{3\sqrt{5}} (-2, 4, 5)^{\mathrm{T}}, p_3 = \frac{1}{3} (1, -2, 2)^{\mathrm{T}}\).
令 \(Q = \begin{bmatrix} \frac{2}{\sqrt{5}} & -\frac{2}{3\sqrt{5}} & \frac{1}{3}\\ \frac{1}{\sqrt{5}} & \frac{4}{3\sqrt{5}} & -\frac{2}{3}\\ 0 & \frac{5}{3\sqrt{5}} & \frac{2}{3} \end{bmatrix}\) ，则有正交变换 \(x = Qy\) ，使得二次型化为标准形 \(f = x^{\mathrm{T}}Ax =\)
\[
\mathbf {y} ^ {\mathrm{T}} \boldsymbol {Q} ^ {\mathrm{T}} \boldsymbol {A} \boldsymbol {Q} \mathbf {y} = 9 y _ {3} ^ {2}.
\]
(3) 由 \(x_{1}^{2} + x_{2}^{2} + x_{3}^{2} = 4\)，得 \(\| x \| = 2\)，由于 \(Q\) 是正交变换，因此 \(\| y \| = 2\)，所以有
\[
f (x _ {1}, x _ {2}, x _ {3}) = 9 y _ {3} ^ {2} \leqslant 9 (y _ {1} ^ {2} + y _ {2} ^ {2} + y _ {3} ^ {2}) = 3 6,
\]
又因为当  \( \mathbf{y}=(0,0,\pm2)^{\mathrm{T}} \)  时， \( f(x_{1},x_{2},x_{3})=36 \) ，所以  \( \max_{x_{1}^{2}+x_{2}^{2}+x_{3}^{2}=4}\{f(x_{1},x_{2},x_{3})\}=36 \) ，此时
\[
\boldsymbol {x} = \binom {x _ {1}} {x _ {2}} = \boldsymbol {Q} \boldsymbol {y} = (\boldsymbol {p} _ {1}, \boldsymbol {p} _ {2}, \boldsymbol {p} _ {3}) \left( \begin{array}{c} 0 \\ 0 \\ \pm 2 \end{array} \right) = \pm 2 \boldsymbol {p} _ {3} = \pm \frac {2}{3} \left( \begin{array}{c} 1 \\ - 2 \\ 2 \end{array} \right).
\]

### 第 22 题 (解答题 · 12分)

设某批电子元件的寿命 X(单位: 小时) 服从参数为  \( \lambda(\lambda>0) \)  的指数分布,  \( X_{1}, X_{2}, \cdots, X_{48} \)  为来自总体 X 的简单随机样本. 记  \( N_{1} \)  表示样本中满足  \( X_{i} \leqslant 100 \)  的  \( X_{i} \)  的个数,  \( N_{2} \)  表示样本中满足  \( 100 < X_{i} < 200 \)  的  \( X_{i} \)  的个数,  \( N_{3} \)  表示样本中满足  \( X_{i} \geqslant 200 \)  的  \( X_{i} \)  的个数.
(1) 若已知 \(\lambda = \frac{\ln 2}{100}\), 求 \(N_{1}, N_{2}, N_{3}\) 两两之间的协方差 \(Cov(N_{1}, N_{2}), Cov(N_{1}, N_{3}), Cov(N_{2}, N_{3})\);
(2) 当 \(\lambda\) 未知时, 由于疏忽, 将样本值数据丢失, 只记得 \(N_{1} = 12\). 在此情况下, 求 \(\lambda\) 的矩估计值 \(\hat{\lambda}\).


<details>
<summary><b>点击查看深度推导与解析</b></summary>

**【解题推导】**：

(1) 由题设可知, X 的分布函数为  \( F(x)=\left\{\begin{aligned}&1-\mathrm{e}^{-\frac{\ln2}{100}x},&x\geqslant0,\\ &0,&x<0,\end{aligned}\right. \)  故
\[
P \{X \leqslant 1 0 0 \} = \frac {1}{2}, P \{1 0 0 <   X <   2 0 0 \} = \frac {1}{4}, P \{X \geqslant 2 0 0 \} = \frac {1}{4},
\]
所以由题意得， \(N_{1}\sim B\left(48,\frac{1}{2}\right),N_{2}\sim B\left(48,\frac{1}{4}\right),N_{3}\sim B\left(48,\frac{1}{4}\right)\) ，从而有
\[
D N _ {1} = 1 2, D N _ {2} = 9, D N _ {3} = 9.
\]
由于  \( N_{1} + N_{2} + N_{3} = 48 \) ，因此  \( \mathrm{Cov}(N_{1} + N_{2} + N_{3}, N_{i}) = \mathrm{Cov}(48, N_{i}) = 0, i = 1, 2, 3 \) ，所以有
\[
1 2 + \operatorname{Cov} (N _ {1}, N _ {2}) + \operatorname{Cov} (N _ {1}, N _ {3}) = 0,
\]
\[
\operatorname{Cov} (N _ {1}, N _ {2}) + 9 + \operatorname{Cov} (N _ {2}, N _ {3}) = 0,
\]
\[
\operatorname{Cov} (N _ {1}, N _ {3}) + \operatorname{Cov} (N _ {2}, N _ {3}) + 9 = 0,
\]
从而有 \(\operatorname{Cov}(N_1, N_2) + \operatorname{Cov}(N_1, N_3) + \operatorname{Cov}(N_2, N_3) = -15\)，所以
\[
\operatorname{Cov} (N _ {1}, N _ {2}) = - 6, \operatorname{Cov} (N _ {1}, N _ {3}) = - 6, \operatorname{Cov} (N _ {2}, N _ {3}) = - 3.
\]
(2) 由于只记得 \(N_{1} = 12\), 即样本中满足 \(X_{i} \leqslant 100\) 的 \(X_{i}\) 的个数为 12, 故表明样本中满足 \(X_{i} > 100\) 的 \(X_{i}\) 的个数为 \(N_{2} + N_{3} = 36\).
构造新总体 \(Y = \begin{cases} 0, & X \leqslant 100, \\ 1, & X > 100, \end{cases}\) 则 \(Y \sim \begin{pmatrix} 0 & 1 \\ 1 - \mathrm{e}^{-100\lambda} & \mathrm{e}^{-100\lambda} \end{pmatrix}\), 因此有 \(EY = \mathrm{e}^{-100\lambda}\). 又对应总体 \(Y\) 的样本值为 12 个, 0 36 个 1, 所以其样本均值为 \(\overline{y} = \frac{0 \times 12 + 1 \times 36}{48} = \frac{3}{4}\), 由 \(EY = \overline{y}\), 即 \(\mathrm{e}^{-100\lambda} = \frac{3}{4}\), 解得 \(\lambda = \frac{1}{100} \ln \frac{4}{3}\), 所以 \(\lambda\) 的矩估计值 \(\hat{\lambda} = \frac{1}{100} \ln \frac{4}{3}\).
